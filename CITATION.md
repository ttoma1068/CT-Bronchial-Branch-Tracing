# How to cite BBT

## Provisional citation

Toma T. *CT-based Bronchial Branch Tracing (BBT): CT-derived virtual bronchoscopy and bronchial branch tracing workflow*. Version 1.0.0. 2026. Software/research workflow.

After the first Zenodo archive, replace this with the version-specific DOI citation.

If BBT materially contributes to a study, method, software system or derivative workflow, please cite the original version, identify the work as based on or adapted from BBT, and describe material modifications.

A modified implementation must not imply endorsement or clinical validation by the original author.
