# How to cite BBT

## Version 1.0.0

Toma T. *CT-based Bronchial Branch Tracing (BBT): CT-derived virtual bronchoscopy and bronchial branch tracing workflow*. Version 1.0.0. 2026. Zenodo. https://doi.org/10.5281/zenodo.23190857

**DOI:** 10.5281/zenodo.23190857

If BBT materially contributes to a study, method, software system or derivative workflow, please cite the specific version used, identify the work as based on or adapted from BBT, and describe material modifications.

A modified implementation must not imply endorsement or clinical validation by the original author.

The archived v1.0.0 release is permanently available through Zenodo at https://doi.org/10.5281/zenodo.23190857.
